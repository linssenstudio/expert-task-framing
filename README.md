# Expert Task Framing

一个给 AI Agent 使用的 Codex Skill。面对海报、写作、产品策划、研究等开放任务时，它帮助 Agent 先找到合适的专家视角，研究优秀从业者如何判断和执行，再把这些做法转成当前任务的工作框架。任务完成后，Agent 可将有证据支持的经验写入本地经验库，供下次参考。

## 它会做什么

1. 明确目标、受众、交付物、限制和成功标准。
2. 找到主要负责这个任务的专家角色，以及必要的协作视角。
3. 查看用户材料、优秀案例、权威资料或专家公开经验，区分事实、推断和待验证假设。
4. 形成适用于当前任务的决策顺序、每步产物和质量检查点。
5. 按框架完成任务，并根据实际结果调整。
6. 将经过验证、可复用的经验写入 `memory/lessons.md`。

它是工作方法，不是某个行业的固定模板。若你只要求思维框架，Agent 会交付框架；若你要求完成具体工作，Agent 应继续产出成品。

## 安装

将本仓库克隆到 Codex 的个人 Skills 目录：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/linssenstudio/expert-task-framing.git ~/.codex/skills/expert-task-framing
```

安装后，`SKILL.md` 应位于 `~/.codex/skills/expert-task-framing/SKILL.md`。在新的 Codex 对话中，可以显式调用 `$expert-task-framing`；对于适合的开放任务，Codex 也可以自动选用它。

如果同名目录已经存在，请先备份里面的 `memory/lessons.md`，再更新文件，避免覆盖你积累的经验。

## 怎么用

在任务前加上 Skill 名称，写清楚实际目标和你已有的材料。例如：

```text
$expert-task-framing
我要做一张新咖啡产品的社交媒体海报。目标是让第一次看到的人记住产品卖点；受众是 20–35 岁的城市上班族。请先用优秀视觉设计师的工作方式建立框架，再完成海报方案。尺寸为 1080×1350，必须包含产品名、价格和购买入口。
```

也可以只要框架：

```text
$expert-task-framing
我准备做一份竞品研究。请先判断由哪些专业角色主导，研究他们通常如何定义问题、选择证据和验证结论，然后给我一套适用于这次研究的执行框架。
```

给 Agent 的信息越具体，框架越容易贴合实际。尤其有用的是：目标、受众、使用场景、必须包含的内容、交付格式、截止时间、已有参考和你判断成功的标准。信息不全时，Skill 会把可继续推进的部分标为假设。

## 经验如何积累

本地文件 `memory/lessons.md` 是经验库。Agent 在开始任务时读取相关记录，在完成任务并观察到结果后，记录适用条件、做法、证据、可信度和反例。没有结果证据的想法应保留为假设，不应写成通用规律。

经验库的更新只发生在你使用的本地副本里，**不会自动同步到 GitHub**。如果想保存到自己的仓库，需要自行提交和推送该文件的修改。不要把客户隐私或未获授权的素材提交到公开仓库。

## 仓库内容

- `SKILL.md`：Agent 的工作指令。
- `memory/lessons.md`：可持续维护的经验库模板。
- `README.md`：安装和使用说明。

这个 Skill 不会保证每个领域都有一套统一的“顶尖专家流程”。它要求 Agent 说明所用依据，并根据当前任务和反馈调整框架。
